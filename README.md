# Star Schema para Análise de Vendas — DIO

## Objetivo

Este repositório apresenta uma adaptação autoral dos conceitos de modelagem dimensional e Star Schema estudados na DIO, aplicados a um cenário de análise de vendas.

## Modelo proposto

O modelo conceitual organiza os dados em uma tabela fato de vendas e dimensões relacionadas a produtos, descontos, calendário e informações complementares.

## Estrutura do projeto

- `modelo_star_schema.md`: visão geral do modelo dimensional.
- `documentacao/`: decisões de modelagem, estrutura e diagrama.
- `sql/`: scripts SQL de exemplo para criação, carga e validação conceitual.
- `dados/`: dados fictícios utilizados como exemplo.

## Status

Este projeto é uma adaptação conceitual. Os scripts SQL e o modelo ainda precisam de validação prática, e o arquivo Power BI (`.pbix`) não foi desenvolvido.

## Observação

O projeto utiliza os conceitos de Star Schema como referência, mas não representa uma implementação concluída do desafio original de vendas da DIO.
