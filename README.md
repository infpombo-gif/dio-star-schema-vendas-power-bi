# Dados de Exemplo

## Objetivo

Este diretório contém dados fictícios para demonstrar a estrutura proposta para o Star Schema de análise da atuação dos professores.

## Arquivo

- `exemplo_modelo.csv`: exemplos de associações entre professores, disciplinas, cursos, departamentos e datas.

## Como interpretar os dados

Cada linha representa uma oferta hipotética de uma disciplina por um professor em um curso, em uma data específica.

Os identificadores são ilustrativos e não correspondem necessariamente aos identificadores do banco relacional original.

## Cuidados

- Os dados são inteiramente fictícios.
- As datas não representam ofertas históricas reais.
- A quantidade de ofertas é demonstrativa.
- O arquivo não foi extraído nem validado em um banco de dados.
- Os dados não devem ser utilizados como evidência de resultados reais.

## Próximas etapas

Para implementar o modelo definitivamente, será necessário relacionar os dados de origem às dimensões, gerar as chaves substitutas, validar a granularidade e configurar os relacionamentos no Power BI.
